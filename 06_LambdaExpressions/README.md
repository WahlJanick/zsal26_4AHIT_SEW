# Lambda Expressions - Praxisübung (ca. 100 Minuten)

Diese Solution enthält sieben Konsolenprojekte mit **unvollständigem Code**. In den
Kommentaren steht, was du mit Lambda Expressions **schreiben**, **anpassen** oder
**verwenden** sollst. Delegates (`Func`, `Action`, `Predicate`) kennst du bereits.

## So arbeitest du

1. Öffne `LambdaPraxis.slnx` in Visual Studio 2026 (.NET 10).
2. Rechtsklick auf das Projekt, **Als Startprojekt festlegen**, dann **F5**.
3. Lies den Kopfkommentar in `Program.cs` und suche nach `TODO`.
4. Das Programm prüft sich selbst:
   - `[OK]` richtig
   - `[FEHLER]` falsch, erwartet und erhaltenen Wert vergleichen
   - `[OFFEN]` noch nicht bearbeitet
5. Ändere nur den Code bei `TODO`. Die Prüfzeilen darunter bleiben unverändert.
6. Arbeite die Projekte der Reihe nach durch. Wenn du hängst, geh zur nächsten Teilaufgabe weiter.

Aufgabentypen: **[SCHREIBEN]** neu schreiben, **[ANPASSEN]** vorhandenen Code ändern,
**[VERWENDEN]** vorhandene Methode mit einer Lambda aufrufen. Aufgaben mit **Zusatz**
sind nicht in der Zeit eingerechnet.
